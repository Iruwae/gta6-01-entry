**SOLMAR BAY** — an original open-world crime game in the spirit of GTA 6, built for make.fun's "Make GTA 6" bounty. Marco Solis is back in Solmar Bay with $120, a debt, and a friend who runs the Bayline garage. Steal cars, outrun the Solmar Bay PD, run packages for Lena Cruz, clear the Dock Rats out of the harbor, and pull the one big score that sets you free.

A sun-soaked coastal city to explore on foot and behind the wheel: live traffic, pedestrians, a wanted level with police cruisers and foot cops who respond, four story missions, combat, a HUD with a live minimap, a start screen and an autosave. Everything — the city, characters, vehicles, names, story, art, sounds and music — is original.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. No build step, no network at runtime — the game is static files under `game/`, Three.js vendored minified under `game/vendor/`.

## Play

- **WASD** move / drive · **Mouse** aim & shoot (drag to orbit the camera) · **F** steal a car / get out
- **E** start a job at the Bayline garage · **Shift** run · **Space** jump · **P** pause · **M** mute
- Crimes raise your wanted level (up to 5 stars); stay clean and the heat fades. Progress saves automatically.
